One-line CLI 2FA generation

            
Compute without the site: copy any snippet into your terminal.

          

          

            

              macOS / Linux (oathtool)
              
            

            
oathtool --totp -b "JBSWY3DPEHPK3PXP"

          

          

            

              Python 3 zero-dependency one-liner
              
            

            
python3 -c "import base64,hmac,hashlib,struct,time;k=base64.b32decode('JBSWY3DPEHPK3PXP',True);h=hmac.new(k,struct.pack('>Q',int(time.time()//30)),hashlib.sha1).digest();o=h[-1]&15;print(f'{(struct.unpack(\">I\",h[o:o+4])[0]&0x7fffffff)%1000000:06d}')"

          

          

            

              Shell alias (zsh / bash)
              
            

            
2fa() { oathtool --totp -b "$1" | pbcopy && echo "✅ Copied 2FA to clipboard"; }

Free Online 2FA / TOTP Authenticator Code Calculator — 100% Local

        

          2fa.pub is a free online two-factor authentication (2FA) code calculator that runs entirely in your browser.
          It works like a web version of Google Authenticator: paste a Base32 secret (or a QR screenshot, an
          otpauth:// link, or a batch of account lines) and get a live
          6-digit TOTP verification code generated with the native Web Crypto API. Nothing is uploaded — secrets
          never leave your device, and there is no account or sign-up required.

What Is a TOTP Code?

        

          TOTP (Time-based One-Time Password, RFC 6238) is the algorithm behind most two-factor authentication apps,
          including Google Authenticator, Microsoft Authenticator, Aegis, and 1Password. It combines your shared
          secret key with the current Unix time (usually in 30-second windows) using an HMAC-SHA1 hash, producing a
          short numeric code that changes every period. Because the code is computed from time and the secret alone,
          both your phone app and the server can verify it without any network request between them.
        

        

          2fa.pub implements the same RFC 6238 algorithm with the browser's built-in Web Crypto API, so results are
          byte-for-byte identical to Google Authenticator — including support for SHA-256/SHA-512, 8-digit codes, and
          custom periods.
        

      


      

        
Frequently Asked Questions

        

          

            
Is it safe to calculate 2FA codes online with 2fa.pub?

            
Yes — 100% local computation. 2fa.pub uses the native browser Web Crypto API so secrets never leave your device, and URL #Hash parameters are strictly stripped from analytics. You can verify this yourself with the browser's F12 network panel: no secret data is ever transmitted.

          

          

            
Does 2fa.pub store my secrets on a server?

            
No. There is no backend database. Secrets live only in the current page's memory; the optional encrypted vault stores entries in your own browser's localStorage, protected by a password only you know. The "burn memory" button wipes everything immediately.

          

          

            
How do I generate a verification code from a Base32 secret?

            
Copy the Base32 secret from your service's 2FA setup page, press Ctrl+V anywhere on 2fa.pub, and the live code appears instantly with a countdown to its expiry. Codes refresh automatically every 30 seconds (or the custom period you configure).

          

          

            
Can I extract secrets from a Google Authenticator export QR code?

            
Yes. Google Authenticator's "Export accounts" feature generates an otpauth-migration:// QR code containing all selected accounts. Upload its screenshot or paste the link and 2fa.pub decodes the protobuf locally to list every issuer, account name, and Base32 secret — see our Google Authenticator export decoding guide.

          

          

            
Does 2fa.pub support Steam Guard codes?

            
Yes. The Steam tab computes Steam Guard codes from your steamid shared secret using Steam's modified base32 alphabet, fully offline.

          

          

            
Why does my code show expired when I paste it?

            
TOTP codes are only valid for the remainder of the current 30-second window. 2fa.pub's smart copy solves this: when 4 seconds or fewer remain, copying automatically grabs the next period (+30s) code so it never expires while you switch windows to paste.

          

          

            
Can I use 2fa.pub offline?

            
Yes. The site is a progressive web app (PWA): after your first visit, all assets are cached locally by a service worker, so the calculator keeps working with no internet connection. Everything — TOTP, QR decode, QR generation, Steam codes — is computed locally.

          

          

            
Which sites and apps work with these codes?

            
Any service that shows a QR code for "authenticator app" setup: GitHub, Google, Microsoft, Amazon AWS, Binance, Coinbase, Discord, Dropbox, and hundreds more. If setup shows a "can't scan?" link, the revealed Base32 secret works directly with 2fa.pub.
